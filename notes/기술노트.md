# 기술 노트 — 다크 메시아(Source 2006) 한글 글꼴·크래시 수정

대상: Steam판 Dark Messiah of Might and Magic Single Player (앱 2100)

## 1. 글꼴: 한글이 언제나 굴림으로 그려지던 이유

### vgui2 — 언어별 스킴 파일을 먼저 읽음
`vgui2.dll`의 스킴 로더는 `resource/SourceScheme.res`를 열기 전에 `%s%s_%s.%s` 형식으로
`resource/SourceScheme_<언어>.res`를 먼저 찾는다. 언어는 레지스트리
`HKCU\Software\Valve\Steam\Language` 값(예: `koreana`).
→ 한국어 Steam에서는 `sourcescheme_koreana.res`, `clientscheme_koreana.res`만 의미가 있다.

### vguimatsurface — 아시아 언어 대체 글꼴
`FontManager`의 글리프 세트 설정 함수(0x100235a0 부근)는

- 요청한 글꼴이 "전 범위 가능 목록"(Marlett, DM, igl, GRN47__C)에 있으면 그 글꼴로 0x0000~0xFFFF 전부
- 아니면 **0x00~0xFF만 요청한 글꼴, 0x100~0xFFFF는 대체 글꼴**로 그린다.

대체 글꼴 이름은 0x100226c0 함수가 돌려주며 NT 계열에서는 항상 `"Tahoma"`(0x100970c0).
Tahoma에는 한글이 없어서 윈도우 글꼴 연결로 굴림이 대신 쓰였다. 스킴에서 글꼴 이름을 아무리 바꿔도 한글은 굴림.

**패치**: `.rdata` 끝 여유 공간(RVA·파일 오프셋 모두 0xaf248)에 `"NanumMyeongjo"`를 쓰고
0x100226c9 `mov eax, 0x100970c0`의 주소를 0x100af248로 바꿈. `.rdata` VirtualSize 0x1a245 → 0x1a260.
재배치 항목은 그대로 유효(이미지 안 주소라 기준 주소 변경 시에도 맞음).

### vguimatsurface — 한글은 안티앨리어싱 없이 그림
글리프 그리기(0x100220c0 부근):
```
cmp ebx, 0xff ; jle +8        ; 0xFF 이하면 그대로
test byte [esi+0x29], 4 ; jne ; FONTFLAG_CUSTOM이면 그대로
xor al, al                    ; 그 밖(한글)은 안티앨리어싱 끔 → ExtTextOutW 경로
```
안티앨리어싱 경로는 `GetGlyphOutlineA(hdc, 유니코드값, GGO_GRAY8_BITMAP, ...)`를 쓰므로
그냥 켜면 한글이 깨진다.

**패치**: `jle`(7E) → `jmp`(EB), 임포트 이름 `GetGlyphOutlineA` → `GetGlyphOutlineW`(힌트 0).
0xFF 이하 글자는 A/W 결과가 같아서 영문에는 영향 없음.

| 파일 오프셋 | 원래 → 바뀜 | 내용 |
|---|---|---|
| 0x220C2 | 7E → EB | 0xFF 초과 글자도 안티앨리어싱 |
| 0x226CA~CC | C0 70 09 → 48 F2 0A | 대체 글꼴 이름 주소 → 0x100AF248 |
| 0xAEB18~19 | 80 01 → 00 00 | 임포트 힌트 |
| 0xAEB29 | 41 → 57 | GetGlyphOutline**A** → **W** |
| 0xAF248~ | 00… → `NanumMyeongjo` | 대체 글꼴 이름 |
| 0x220 | 45 A2 01 00 → 60 A2 01 00 | `.rdata` VirtualSize |

### 스킴 파일
- 굴림/Tahoma/Verdana/Arial/Trebuchet(숫자용 HUDNumber 제외)/cochin → `NanumMyeongjo`
- 바꾼 글꼴에 `antialias 1`, 기울임 끔
- `CustomFontFiles`에 `resource/NanumMyeongjo.ttf`, `NanumMyeongjoBold.ttf` 추가
- `*_blabla`(로딩 화면 설명 글) 크기 ×30/28

## 2. 세이브/로드 날짜 깨짐 — `filesystem_steam.dll`
`FileTimeToString`(0x10002100 부근)이 `GetDateFormatA(LOCALE_USER_DEFAULT, DATE_LONGDATE)` +
`GetTimeFormatA(..., 0)`로 CP949 문자열을 만들고, GameUI 라벨은 이를 UTF-8로 해석해 한글이 깨짐.

| 파일 오프셋 | 원래 → 바뀜 | 내용 |
|---|---|---|
| 0x2185 | 02 → 01 | DATE_LONGDATE → DATE_SHORTDATE (`2026-11-14`) |
| 0x21A3 | 00 → 0E | TIME_NOSECONDS·NOTIMEMARKER·FORCE24HOURFORMAT (`20:07`) |

## 3. 튕김
- **메모리**: `mm.exe` PE 헤더 Characteristics(파일 0xDD6) 0x0F → 0x2F (Large Address Aware).
- **자막 꺾쇠**: 자막(closecaption)에서 `< >`는 명령어(`<clr:...>`, `<I>`, `<sfx>` 등).
  꺾쇠 안에 한글을 넣으면(`<힘쓰는 사이클롭스 소리>`) 그 자막이 뜨는 순간 게임이 튕김.
  영어 원본의 몬스터 효과음 자막(`<ghost noises>` 등)은 모르는 명령어라 원래 화면에 안 나오므로,
  번역하지 말고 넣지 않는 것이 맞다.
